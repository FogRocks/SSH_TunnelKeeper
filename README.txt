SSH TunnelKeeper
================

Что это
-------
Один файл SSH_TunnelKeeper.bat, который поднимает ОБРАТНЫЙ SSH-туннель:
порты вашего ПК становятся доступны через удалённый SSH-сервер снаружи.
Внешние устройства подключаются к вашему компьютеру, даже если у вас нет
белого IP-адреса и настройки роутера.

Зачем нужен
-----------
- Доступ к рабочему столу (RDP), сетевым папкам (SMB) и другим локальным
  службам из любой точки мира.
- Не нужен белый IP, проброс портов на роутере или DMZ.

Как пользоваться
----------------
1. Двойной клик по SSH_TunnelKeeper.bat (потребуются права администратора).
2. В меню выбрать "1) Установить".
3. Указать SSH-сервер, пользователя и SSH-порт.
   При повторной установке прошлые значения (сервер/пользователь/порт)
   подставляются по умолчанию — просто нажмите Enter, чтобы их принять.
4. Если ssh-ключа нет — скрипт создаст его и покажет на экране; эту строку
   добавьте на сервер в ~/.ssh/authorized_keys и нажмите любую клавишу
   (Esc — отменить установку).
5. Скрипт проверит вход по ключу и спросит пробросы портов
   (удалённый_порт:локальный_порт, можно несколько через запятую).
6. При желании введите пароль Windows — тогда туннель будет подниматься
   ещё до входа в систему (если пароль не подошёл, задача всё равно
   ставится и работает при входе).

Что умеет (меню)
----------------
1) Установить                 - первичная настройка и создание задачи
2) Удалить                    - удаление задачи (1-3: только задача /
                                 +настройки и лог / +ключ)
3) Статус                     - состояние задачи, порты, ключ, лог
4) Изменить                   - добавить/удалить/изменить пробросы,
                                 сменить сервер, показать/создать ключ
5) Остановить туннель         - остановить И отключить задачу
                                 (иначе «сторож» запустил бы её снова
                                 максимум через минуту)
6) Завершить все ssh-туннели  - найти и закрыть любые ssh-процессы
                                 и подозрительные задачи планировщика
7) Выход

Что делает автоматически
------------------------
- ставит ssh-ключ и авторизуется без пароля;
- создаёт задачу планировщика: старт системы + при входе + контроль
  каждую минуту + автоперезапуск при сбое (таймаута нет);
- держит туннель постоянно (keepalive, повторные попытки), пишет лог
  (при > 1 МБ откатывается в .old);
- проверяет ключ сервера (StrictHostKeyChecking=accept-new, OpenSSH ≥ 7.6);
  на старых ssh без поддержки опции — fallback no;
- хранит настройки в скрытом файле %USERPROFILE%\.ssh\;
- хранит known_hosts туннеля отдельно: %USERPROFILE%\.ssh\ssh_tunnelkeeper_known_hosts
  (не во %TEMP% — очистка temp не сбрасывает проверку ключа сервера);
- при генерации ключа предлагает выбрать парольную фразу: ключ БЕЗ фразы
  нужен для автозапуска до входа в систему, ключ С фразой безопаснее, но
  автозапуск до входа невозможен без ssh-agent/Pageant;
- сохраняет копию себя в %USERPROFILE%\.ssh\ — установщик можно удалить.

Безопасность
------------
- Используется проверка ключа SSH-сервера (защита от MITM, при поддержке
  accept-new): новый ключ принимается один раз, при его смене соединение
  отклоняется.
- Имена пользователя/сервера валидируются, ssh/ssh-keygen вызываются по
  абсолютным системным путям (защита от подмены PATH).
- Завершаются только ssh-процессы этого туннеля (по known_hosts + флагу -NR),
  чужие ssh-сессии не трогаются.

Примечания
----------
- На сервере в sshd_config должны быть разрешены:
  AllowTcpForwarding yes, GatewayPorts yes (для внешних подключений).
