# SSH TunnelKeeper

Менеджер **обратных SSH-туннелей** (`-R` / RemoteForward) для Windows: один
файл, который открывает порты вашего ПК через удалённый SSH-сервер. Белый IP,
проброс портов на роутере и DMZ не нужны.

## Возможности

- Обратный туннель: доступ к RDP, SMB и другим локальным службам из любой точки.
- Автозапуск через задачу планировщика: старт системы, вход, «сторож» раз в минуту,
  перезапуск при сбое без таймаута.
- Вход по ssh-ключу без пароля; проверка ключа сервера (защита от MITM).
- Чистое удаление: скрипт не оставляет своих файлов.
- Помощь (пункт меню 7): готовые команды firewall/sshd для сервера с
  подставленными портами.
- Всё в одном `.bat` — ничего не требуется компилировать.

## Быстрый старт

1. Скачать и распаковать `SSH_TunnelKeeper.zip`.
2. Запустить `SSH_TunnelKeeper.bat` (нужны права администратора).
3. В меню выбрать **1) Установить** и следовать шагам мастера.
4. Если ключа нет — скрипт создаст его; добавьте строку на сервер в
   `~/.ssh/authorized_keys`.

## Требования

Windows 10/11, клиент OpenSSH, PowerShell 5.1+, права администратора.
На сервере в `sshd_config`: `AllowTcpForwarding yes`, `GatewayPorts yes`.

## Безопасность

- В коде нет вшитых паролей, серверов и логинов.
- Приватный ключ не покидает машину; наружу выводится только публичный.
- Завершаются только ssh-процессы этого туннеля.
- Обратный туннель публикует порты на сервере (`GatewayPorts`) — ограничьте
  доступ к ним на сервере через firewall (разрешить только свои IP), иначе
  RDP/SMB будут видны всему интернету. Это настройка сервера, не клиента.
- Используйте только свои серверы с корректными ACL и firewall.
